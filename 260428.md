## Zusammenfassung Theorie
+ Exit-Status: `$?` → 0 = Erfolg (true), ≠0 = Fehler (false)
+ `test` prüft Bedingungen → Ergebnis im Exit-Status
+ Beispiele: `=` (String), `-eq`, `-gt`, `-lt` (Zahlen)
+ `exit <code>` setzt Status im Skript
+ `&&` → nächster Befehl nur bei Erfolg (0)
+ `||` → nächster Befehl nur bei Fehler (≠0)

## Übung (Datei zu groß)
Schreibe ein Skript mit einer Datei als Argument, es soll der Text `Datei ist zu groß` ausgegeben werden wenn die Datei mehr als 100 Bytes hat. Die Dateigröße kann mit `ls -l` und anschließendes `cut` ermittelt werden.

V1.1: Wenn die Datei nicht mehr als 100 Bytes hat soll der Text `Größe OK` ausgegeben werden.

# 

Zuerst wurde ein Shellskript erstellt mit dem Befehl:`nano check_size.sh`

Anschließend wurde in das Skript folgender Code eingefügt:

```
#!/bin/bash
 
# Datei aus Argument
file=$1
 
# Dateigröße holen (5. Spalte von ls -l)
size=$(ls -l "$file" | cut -d ' ' -f5)
 
# Vergleich
if [ "$size" -gt 100 ]; then
    echo "Datei ist zu groß"
else
    echo "Größe OK"
fi
```

Danach wurde die Datei gespeichert und der Editor geschlossen.

Im nächsten Schritt wurde das Skript ausführbar gemacht mit:
`chmod +x check_size.sh`

Anschließend wurde das Skript mit zwei Zahlen ausgeführt:
`./check_size.sh test.txt`

Ergebnis:

```

└─$ nano check_size.sh
                                
┌──(kali㉿kali)-[~]
└─$ chmod +x check_size.sh

┌──(kali㉿kali)-[~]
└─$ ./check_size.sh test.txt

```

## Übung (HTML Generator)
Erstelle ein Skript das ein Markdown Dokument nach HTML konvertiert:

`$ ./md2html test.md test.html`

Verwende `pandoc` zum konvertieren.

Dabei soll aber nur dann konvertiert werden wenn dies wirklich notwendig ist, d.h. die html Zieldatei entweder nicht existiert oder älter ist als die Quelldatei, denn wenn sich die Quelldatei nicht geändert hat ist das konvertieren auch nicht notwendig.

#

Zuerst wurde ein Shellskript erstellt mit dem Befehl:
`nano md2html.sh`

Anschließend wurde in das Skript folgender Code eingefügt:

```
#!/bin/bash
 
src=$1
dest=$2
 
# Prüfen ob Argumente vorhanden sind
if [ -z "$src" ] || [ -z "$dest" ]; then
    echo "Verwendung: ./md2html input.md output.html"
    exit 1
fi
 
# Prüfen ob Quelldatei existiert
if [ ! -e "$src" ]; then
    echo "Fehler: Quelldatei existiert nicht!"
    exit 1
fi
 
# Nur konvertieren wenn nötig
if [ ! -e "$dest" ] || [ "$src" -nt "$dest" ]; then
    pandoc "$src" -o "$dest"
    echo "Konvertiert: $src → $dest"
else
    echo "Keine Änderung – Konvertierung nicht nötig."
fi
```

Danach wurde die Datei gespeichert und der Editor geschlossen.

Im nächsten Schritt wurde das Skript ausführbar gemacht mit:
`chmod +x md2html.sh`

Danach wurde die pandoc installiert mit: `sudo apt install pandoc`

Anschließend wurde eine Testdatei erstellt:
`echo "# Hallo Welt" > test.md`

Danach wurde das Skript ausgeführt mit:
`./md2html.sh test.md test.html`

Ergebnis:

```
┌──(kali㉿kali)-[~]
└─$ nano md2html.sh       

┌──(kali㉿kali)-[~]
└─$ chmod +x md2html.sh 

┌──(kali㉿kali)-[~]
└─$ sudo apt install pandoc
                          
┌──(kali㉿kali)-[~]
└─$ echo "Hallo" > test.md 
                                                                
┌──(kali㉿kali)-[~]
└─$ ./md2html.sh test.md test.html
Konvertiert: test.md → test.html
```


Beim erneuten Ausführen ohne Änderungen:

```

```

## Übung (C-Programm)
Schreibe und kompiliere ein C-Programm das 2 Argumente über die Kommandozeile erhält. Das Programm soll die Differenz ausgeben und im exit Status anzeigen ob die erste Zahl größer als die zweite Zahl war. Teste den exit Status mit `&&`. Lass dir dabei von genAI helfen.

#

Zuerst wurde ein C-Programm erstellt mit dem Befehl:
`nano diff.c`

Anschließend wurde in das Programm folgender Code eingefügt:

```
#include <stdio.h>
#include <stdlib.h>
 
int main(int argc, char *argv[]) {
 
    if (argc != 3) {
        printf("Verwendung: ./diff zahl1 zahl2\n");
        return 1;
    }
 
    int a = atoi(argv[1]);
    int b = atoi(argv[2]);
 
    int diff = a - b;
 
    printf("Differenz: %d\n", diff);
 
    if (a > b) {
        return 0;
    } else {
        return 1;
    }
}
```

Im nächsten Schritt wurde das Programm kompiliert mit:
