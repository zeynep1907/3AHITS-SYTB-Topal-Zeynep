# 1. Übung (Browser Developer Tool)
+ Starte den Chrome Browser und öffne mit F12 die Developer Tools, wechsle auf den Network Tab, deaktiviere den Cache. Lade dann diese Seite im Browser. Du siehst nun alle Netzwerkzugriffe die beim öffnen dieser Seite ausgeführt werden.

+ Mache weiters einen Rechtsklick auf den Netzwerkzugriff mit dem die CSS Datei (style.css) geladen wird. Mit Copy » Copy as cURL wird eine curl Kommandozeile erzeugt die genau diesen Netzwerkzugriff nachstellt. Der Server kann diesen mit curl erzeugten Request nicht vom Request des Browsers unterscheiden. Das eröffnet viele “Hacking” Möglichkeiten.

Zuerst wurde eine Browser(HTL-Braunau) gestartet und mit der Taste F12 die Developer Tools geöffnet. Anschließend wurde in den Reiter „Network“ gewechselt. Dort wurde die Option „Disable cache“ aktiviert, damit alle Dateien bei jedem Neuladen vollständig vom Server geladen werden.

Danach wurde die Webseite neu geladen. Im Network‑Tab erschienen nun alle Netzwerkzugriffe, die beim Laden der Seite durchgeführt wurden, wie `html`, `css`, `js` und etc.

In der CSS Lise wurde eine Datei vom Typ `stylesheet`ausgewählt. Ich habe mich für die erste Datei entschieden.

Auf den ausgewählten Netzwerkzugriff wurde mit der rechten Maustaste geklickt. Über Copy `->`Copy as `cURL` wurde eine vollständige `cURL`- Kommandozeile erzeugt. Diese enthält alle Informationen des ursprünglichen Browser-Requests, zum Beispiel : `url`, `http`, `cookies`und etc.

Anschließend wurde das Kali‑Linux‑Terminal geöffnet. Der kopierte `cURL`‑Befehl wurde eingefügt und ausgeführt. Das Terminal stellte daraufhin denselben Request an den Server wie zuvor der Browser.

# Übung (curl und Notenmanagement)
+ Starte Chrome.
+ Öffne mit Ctrl + Shift + I (oder F12) die Browser Developer Tools. Deaktiviere den Cache im Network Tab.
+ Lade HTL Braunau Notenmanagment.
+ Logge dich im Notenmanagement ein und lade die Ergebnisse einer Leistungsfeststellung.
+ Im Netzwerk-Tab: Finde den API Request der die angezeigten Daten aus dem Notenmanagement abruft (werden als JSON übertragen).
+ Mache den gleichen Request mit curl.

Zuerst wurde Google Chrome gestartet.

Mit `F12` wurden die Developer Tools geöffnet.

Anschließend wurde in den Reiter Network gewechselt und die Option `Disable cache` aktiviert, damit alle Daten direkt vom Server geladen werden. 

Danach wurde das HTL-Braunau-Notenmanagement geöffnet und eine Anmeldung mit gültigen Zugangsdaten durchgeführt.
Nach dem Login wurde eine Leistungsfeststellung ausgewählt, sodass die Noten angezeigt wurden.

 Im Network-Tab wurden viele Netzwerkzugriffe sichtbar.

Um den richtigen Request zu finden, wird im `Fetch/XHR` gesucht.
Der passende Eintrag war jener Request, der die Notendaten vom Server abrief.

Dieser Request lieferte die Daten im `JSON`-Format.

`JSON` ist ein Datenformat, das häufig von Web-APIs verwendet wird. Auf den gefundenen Request wurde mit der rechten Maustaste geklickt.

Über Copy `->` Copy as cURL wurde eine vollständige `cURL`-Kommandozeile erstellt. Das Terminal wurde geöffnet.

Der kopierte Befehl wurde eingefügt und mit Enter ausgeführt.
Daraufhin sendete das Terminal denselben Request an den Server wie zuvor der Browser.
