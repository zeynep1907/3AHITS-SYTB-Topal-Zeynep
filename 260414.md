## Berechnungen

Berechnungen `(+, -, *, /, %)` können mit der Syntax `$(( EXPR ))` durchgeführt werden:
```
X=99999
Y=88888
Z=$(( X - Y ))
echo $Z

11111
```

Im Kali Linux Terminal wurden mit Command Substitution `($(( ... )))` Berechnungen durchgeführt.

Zuerst wurden Variablen definiert, danach eine Addition ausgeführt und das Ergebnis mit `echo` ausgegeben.

Diese Methode ermöglicht einfache mathematische Berechnungen direkt in der Bash.

+ Addition

```
┌──(kali㉿kali)-[~]
└─$ x=20
                                                                             
┌──(kali㉿kali)-[~]
└─$ Y=5
                                                                             
┌──(kali㉿kali)-[~]
└─$ Z=$(( x + Y ))
                                                                             
┌──(kali㉿kali)-[~]
└─$ echo $Z                        
25
```

+ Subtraktion
  
```
┌──(kali㉿kali)-[~]
└─$ A=25
                                                                             
┌──(kali㉿kali)-[~]
└─$ B=45
                                                                             
┌──(kali㉿kali)-[~]
└─$ echo $((A - B))   
-20
```

## Übung (Anzahl Einträge in einem Verzeichnis)

Schreibe ein shellscript das als Argument einen Pfad auf ein Verzeichnis erhält. Das Script soll die Anzahl der Einträge in diesem Verzeichnis als Zahl ausgeben. Dies soll aus der `l`s Ausgabe mit `wc` ermittelt werden.
```
$ ./nbrentries.sh ~/test
Es sind 12 Einträge im dir ~/test
```
Zuerst wurde ein Shellscript mit `nano nbrentries.sh` erstellt. In das Script wurde folgender Code eingefügt: 
```
#!/bin/bash
 
DIR=$1

ANZAHL=$(ls "$DIR" | wc -l)
 
echo "Es sind $ANZAHL Einträge im dir $DIR"
 ```

Danach wurde das Script mit `chmod +x nbrentries.sh` ausführbar gemacht und mit `./nbrentries.sh ~/test` ausgeführt. 
```
┌──(kali㉿kali)-[~]
└─$ nano nbrentries.sh
                                                                             
┌──(kali㉿kali)-[~]
└─$ chmod +x nbrentries.sh
              
┌──(kali㉿kali)-[~]
└─$ mkdir ~/test
                                                                             
┌──(kali㉿kali)-[~]
└─$ touch ~/test/datei1
                                                                             
┌──(kali㉿kali)-[~]
└─$ touch ~/test/datei2 
                                                                             
┌──(kali㉿kali)-[~]
└─$ touch ~/test/datei3
                                                                             
┌──(kali㉿kali)-[~]
└─$ ./nbrentries.sh ~/test 
Es sind 3 Einträge im dir /home/kali/test
```
## Übung (Tage bis zum Ball)
Schreibe ein Shell-Skript das die Anzahl der Tage bis zum HTL Ball ermittelt. Die Ausgabe soll in der folgenden Form sein.
```
Es sind noch 42 Tage bis zum HTL Ball (2027-01-16)
```
Hinweise:
 Verwende das `date` Format für `seconds since the Epoch (1970-01-01 00:00 UTC)`


Es wurde mit `nano ball.sh` ein Shellscript erstellt und den Code eingefügt. 
```
#!/bin/bash
 
BALL="2027-01-16"
 
JETZT=$(date +%s)
BALL_SEK=$(date -d "$BALL" +%s)
 
DIFF=$(( (BALL_SEK - JETZT) / 86400 ))
 
echo "Es sind noch $DIFF Tage bis zum HTL Ball ($BALL)"
```
Anschließend wurde das Script mit `chmod +x ball.sh` ausführbar gemacht und mit `./ball.sh` gestartet. 
```
┌──(kali㉿kali)-[~]
└─$ nano ball.sh      
                                                                             
┌──(kali㉿kali)-[~]
└─$ chmod +x ball.sh      
                                                                             
┌──(kali㉿kali)-[~]
└─$ ./ball.sh             
Es sind noch 276 Tage bis zum HTL Ball (2027-01-16)
```
## Übung (Zufälliger Satz)
Erstelle ein Skript das einen Satz aus 5 zufälligen Wörtern bildet, z.B.:
```
richtig ganzen Kilometer auf Mittel
```
Wähle die Wörter aus dieser Wortliste.
+ Hinweis: Das Komando `sed -n 5p datei.txt` gibt die 5te Zeile aus.
+ Erweiterung: Das Skript soll auch die Anzahl der in der Wortliste enthaltenen Wörter ermitteln. D.h. die Konstante 1000 soll im Skript nicht vorkommen.

Es wurde mit `nano randomsatz.sh` ein Shellscript erstellt und den Code eingefügt. 
```
#!/bin/bash
 
DATEI="wortliste.txt"
 
ANZAHL=$(wc -l < "$DATEI")
 
W1=$(sed -n "$((RANDOM % ANZAHL + 1))p" "$DATEI")
W2=$(sed -n "$((RANDOM % ANZAHL + 1))p" "$DATEI")
W3=$(sed -n "$((RANDOM % ANZAHL + 1))p" "$DATEI")
W4=$(sed -n "$((RANDOM % ANZAHL + 1))p" "$DATEI")
W5=$(sed -n "$((RANDOM % ANZAHL + 1))p" "$DATEI")
 
echo "$W1 $W2 $W3 $W4 $W5"
```

Danach wurde mit `nano wortliste.txt` eine Wortliste erstellt und mehrere Wörter eingetragen.

Anschließend wurde das Script mit `chmod +x randomsatz.sh` ausführbar gemacht und mit `./randomsatz.sh`gestartet.

##  Übung (dated copy V1)
Create a script which will take a filename as its first argument and create a dated copy of the file. eg. if our file was named file1.txt and today is the 2021-10-29 it would create a copy such as `2021-10-29_file1.txt`.(To achieve this you will probably want to play with command substitution and the command date)

Zuerst wurde mit `nano datedcopy.sh` ein Shellscript erstellt und den Code eingefügt.
```
#!/bin/bash
 
FILE=$1
DATE=$(date +%F)
 
cp "$FILE" "${DATE}_$FILE"
 
echo "Kopie erstellt: ${DATE}_$FILE"
```
Anschließend wurde das Script mit `chmod +x datedcopy.sh` ausführbar gemacht und mit `./datedcopy.sh file1.txt` getestet.

```
┌──(kali㉿kali)-[~]
└─$ nano datedcopy.sh 
                                                                             
┌──(kali㉿kali)-[~]
└─$ chmod +x datedcopy.sh                                                 
┌──(kali㉿kali)-[~]
└─$ echo "Testinhalt" > file1.txt  
                                                                             
┌──(kali㉿kali)-[~]
└─$ ./datedcopy.sh file1.txt
Kopie erstellt: 2026-04-14_file1.txt
```

## Übung (dated copy V2) 
Challenge: To make it a bit harder, see if you can get it so that the date is after the name of the file eg. `file1_2021-10-29.txt` (Hint: Use `cut` to seperate filename from extension, like: `echo "filename.ext" | cut ...`)

Mit `nano datedcopy_v2.sh`wurde ein Shellscript erstellt und den Code eingefügt.
```
#!/bin/bash
 
FILE=$1
 
NAME=$(echo "$FILE" | cut -d '.' -f1)
EXT=$(echo "$FILE" | cut -d '.' -f2)
DATE=$(date +%F)
 
cp "$FILE" "${NAME}_${DATE}.${EXT}"
 
echo "Kopie erstellt: ${NAME}_${DATE}.${EXT}"
```
Anschließend wurde das Script mit `chmod +x datedcopy_v2.sh` ausführbar gemacht und mit `./datedcopy_v2.sh file1.txt` getestet. Dadurch wird eine Kopie der Datei mit Datum im Dateinamen erstellt.
```                        
┌──(kali㉿kali)-[~]
└─$ nano datedcopy_v2.sh
                                                                             
┌──(kali㉿kali)-[~]
└─$ chmod +x datedcopy_v2.sh
                                                                             
┌──(kali㉿kali)-[~]
└─$ echo "test" > file1.txt      
                                                                             
┌──(kali㉿kali)-[~]
└─$ ./datedcopy_v2.sh file1.txt
Kopie erstellt: file1_2026-04-14.txt
```
