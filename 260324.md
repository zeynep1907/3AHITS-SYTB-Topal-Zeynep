## Zusammenfassung Theorie
In diesem Shell-Skript werden verschiedene Befehle der Bash verwendet und ausprobiert.

Am Anfang gibt der Befehl `echo` Text in der Konsole aus. Dabei wird auch eine Variable (`MYVAR`) mit ausgegeben, falls sie gesetzt ist. Danach wird der Text „Guten Morgen“ angezeigt.

Anschließend werden Variablen für einen Dateinamen `FILE_NAME` und einen Ordnernamen `DIR_NAME` erstellt.

Der Befehl `mkdir` würde einen neuen Ordner mit diesem Namen erstellen.
Mit `echo "Hallo" > $DIR_NAME/$FILE_NAME` wird Text in eine Datei geschrieben. Das Zeichen `>` sorgt dafür, dass der Text in die angegebene Datei gespeichert wird.
Danach wird gezeigt, wie Anführungszeichen funktionieren:

+ Mit doppelten Anführungszeichen werden Variablen ersetzt.
Beispiel: Der Name aus der Variable NAME wird im Text eingefügt.
+ Mit einfachen Anführungszeichen werden Variablen nicht ersetzt.
Der Text wird genau so ausgegeben, wie er geschrieben wurde.

Zum Schluss wird gezeigt, wie Variablen in Dateinamen verwendet werden.

Ohne geschweifte Klammern kann die Shell den Variablennamen falsch verstehen, zum Beispiel bei `$FILE_001.txt`.

Mit `${FILE}_001.txt` wird klar, dass nur `FILE` die Variable ist und der Rest normaler Text.

## Übung (Variablen)

Löse diese Aufgabe ohne ein shell-script zu schreiben.

Lege 2 Variablen für Directories an, eine Variable für den Filenamen und eine Variable für die Dateiendung (Extension).

Verwende nur die Variablen anstatt der Directory und Filenamen um folgendes zu lösen:

Erzeuge die Directories (das zweite befindet sich in dem ersten).
Lege in dem zweiten Directory eine Text-Datei mit Inhalt an, verwende Filenamen und Extension (getrennt mit .).
Gib den Inhalt der Datei (unter Verwendung der Variablen) aus.
#
+ Variablen definieren

Trennung von Ordnern, Dateinamen und Extension erhöht die Lesbarkeit.

Einfaches Ändern ohne jede Zeile im Script anfassen zu müssen.
```
DIR1="mein Ordner"
DIR2="unter Ordner"

FILE_NAME="meine Datei"
EXT="txt"
```
# 
+ Ordner erstellen
```
mkdir -p "$DIR1/$DIR2"
```
Warum `-p`:
+ Erstellt Unterordner automatisch, falls sie noch nicht existieren.
+ Verhindert Fehler, wenn `$DIR1` oder `$DIR2` noch nicht angelegt sind.

Warum Quotes:
+ Damit Pfade mit Leerzeichen korrekt interpretiert werden.
# 
+ Datei ertellen
```
echo "Hallo!" > "$DIR1/$DIR2/$FILE_NAME.$EXT"
```
Warum Punkt zwischen Name & Extension:
+ Standardformat für Dateiendungen `name.txt`
+ Trennt variablen Dateinamen sauber von der Extension.

Warum `>` statt `>>`:
+ `>` überschreibt die Datei, falls sie existiert, was für Übungszwecke sicher ist.
#
+ Inhalt ausgeben
```
cat "$DIR1/$DIR2/$FILE_NAME.$EXT"
```
+ Kontrolle, dass die Datei korrekt erstellt wurde.
+ Zeigt, dass Variable + Pfad + Dateiname korrekt zusammenarbeiten.
# 
+ Ergebnis
```
Hallo!
```

## Übung (Begrüßung)

Schreibe ein Shell-Script mit dem Namen `begruessung.sh`, dieses soll:
+ den Benutzer nach seinem Namen fragen
+ den Namen einlesen und in einer Variable speichern
+ danach ausgeben:
```
Hallo <NAME>
Schön, dass du da bist.
```
Starte das Script auf alle besprochene Arten.

Hinweis: Verwende den `read` Befehl – recherchiere wie dieser zu verwenden ist.
# 
## Script erstellen
```
#!/bin/env bash

echo "Wie heißt du?"

read NAME

echo "Hallo $NAME"
echo "Schön, dass du da bist."
```
+ `read NAME` liest die Eingabe vom Benutzer und speichert sie in der Variablen `NAME`.
+ `echo "Hallo $NAME"` zeigt die Variable in der Ausgabe an.
# 
+ Script ausführbar machen
```
chmod +x begruessung.sh
```
#
+ Script starten
```
./begruessung.sh
```
#
+ Ergebnis
```
Wie heißt du?
Zeynep
Hallo Zeynep
Schön das du da bist.
```
