## Zusammenfassung Theorie
1. While-Schleife

```
counter=1
while ((counter <=10))
```

Die While-Schleife wiederholt die Anweisungen solange die Bedingung wahr ist. Hier werden die Zahlen von 1 bis 10 ausgegeben. Mit `((counter++))` wird der Zähler nach jedem Durchlauf um 1 erhöht.

2. For-Schleife mit Liste

```
data="1 2 3 4 5 6 7"
for d in $data
```

Die For-Schleife durchläuft alle Werte der Liste und gibt sie nacheinander aus.

3. Kommandozeilenargumente

```
for arg in $@
```

`$@` enthält alle Argumente, die beim Start des Skripts übergeben wurden. Die Schleife gibt jedes Argument einzeln aus.

4. Brace Expansion

```
for value in {20..25}
```

Mit der Brace Expansion wird automatisch eine Zahlenfolge von 20 bis 25 erzeugt und ausgegeben.

5. Field Separator (IFS)

```
IFS=","
```

`IFS` (Internal Field Separator) legt fest, wie eine Zeichenkette getrennt wird. Hier wird das Komma als Trennzeichen verwendet. Dadurch wird die Variable `mylist` an den Kommata aufgeteilt und die einzelnen Teile werden ausgegeben.
 

## Übung (Even/Odd)
Create a simple script which will print the numbers 1–42 (each on a separate line) and whether they are even or odd.

Zuerst wurde im Terminal eine neue Datei erstellt:
`nano schleifen.sh`

Anschließend wurde folgender Code eingegeben:

```
#!/bin/bash
for number in {1..42}
do
    if (( number % 2 == 0 ))
    then
        echo "$number even"
    else
        echo "$number odd"
    fi
done
```

Die For-Schleife läuft alle Zahlen von 1 bis 42 durch. Mit dem Modulo-Operator `%` wird geprüft, ob der Rest bei der Division durch 2 gleich 0 ist. Ist dies der Fall, wird `even` ausgegeben, sonst `odd`.

`chmod +x schleifen.sh`

## Übung (Summe und Maximum)
Schreibe ein bash Skript das eine beliebige Menge von positiven Zahlen als Argumente aus der Kommandozeile übernimmt. Es soll die Summe und die größte Zahl ausgegeben werden. Hinweis: Verwende `#@`.

In dem Skript wurde folgender Code eingegeben:

```
#!/bin/bash
summe=0
max=$1
for zahl in $@
do
    ((summe += zahl))
    if (( zahl > max ))
    then
        max=$zahl
    fi
done
echo "Summe: $summe"
echo "Maximum: $max"
```

Die Variable `summe` speichert die Summe aller Zahlen. Die Variable `max` wird zunächst mit dem ersten Argument belegt.

Anschließend werden alle übergebenen Zahlen mit einer For-Schleife durchlaufen. Dabei wird jede Zahl zur Summe addiert und geprüft, ob sie größer als das aktuelle Maximum ist.

Das Skript wurde mit mehreren Zahlen gestartet:
`./schleifen.sh 5 8 3 12 7`

Ergebnis

```
┌──(kali㉿kali)-[~/260616]
└─$ ./schleifen.sh 5 8 3 12 6 7
Sume: 41
Maximum: 12
```

## Übung (Min)
Schreibe ein bash Skript das den Namen einer Datei als Argument akzeptiert:

```
$ ./min.sh input.txt
```

Die Input Datei enthält positive Zahlen die durch white spaces getrennt sind:

```
42
21 57
68 33 1
1
```

Das Skript soll die kleinste Zahl ermitteln und ausgeben.

Hinweis:

Der größte mögliche Wert in bash scripting ist 64 Bit signed

```
$ ((MAXINT=2**63-1))
$ echo $MAXINT
9223372036854775807
```

Zuerst wurde eine neue Skriptdatei erstellt:
`nano min.sh`

Im Skript wurde dieser Code eingegeben:

```
#!/bin/bash
 
((MIN=2**63-1))
 
for zahl in $(cat $1)
do
    if (( zahl < MIN ))
    then
        MIN=$zahl
    fi
done
 
echo "Minimum: $MIN"
```

Es wurde eine Datei mit dem Namen `input.txt` erstellt:
`nano input.txt`

Folgende Zahlen wurden eingegeben:

```
42
21 57
68 33 1
1
```

Anschließend wurden alle Zahlen der Datei mit einer For-Schleife durchlaufen. Für jede Zahl wurde geprüft, ob sie kleiner als das aktuelle Minimum ist. Falls ja, wurde `MIN` aktualisiert.

Datei ausführbar machen

## Übung (Durchschnitt)
Schreibe ein bash Skript das eine beliebige Anzahl von Zahlen von stdin akzeptiert und den (ganzzahligen) Durchschnitt der Zahlen ausgibt.

```
$ echo 3 5 7 2 4 | ./avg.sh
```

Wie Daten von stdin gelesen werden können ist zu recherchieren.

Teste das Skript und verwende dieses dann um den Durchschnitts-Wert für die Spalte Stück in der Datei lager.csv zu finden. Hinweis: Verwende cut und tail für die vorverarbeitung der Daten.

Zuerst wurde eine neue Datei erstellt:
`nano avg.sh`

In die Datei wurde folgender Code eingegeben:

```
#!/bin/bash
read zahlen
summe=0
anzahl=0
for zahl in $zahlen
do
    ((summe += zahl))
    ((anzahl++))
done
durchschnitt=$((summe / anzahl))
echo "Durchschnitt: $durchschnitt"
```

`read zahlen` liest die Eingabe von `stdin` ein.

`summe=0` initialisiert die Summe.

`anzahl=0 zählt` die eingegebenen Zahlen.

Die For-Schleife durchläuft alle Zahlen.
Jede Zahl wird zur Summe addiert und die Anzahl erhöht.

Mit `durchschnitt=$((summe / anzahl))` wird der ganzzahlige Durchschnitt berechnet.

Das Ergebnis wird mit `echo` ausgegeben.

Skript ausführbar machen
`chmod +x avg.sh`

Folgender Test wurde durchgeführt:
`echo 3 5 7 2 4 | ./avg.sh`

Ergebnis

```

└─$ nano avg.sh   
                                                                             
┌──(kali㉿kali)-[~/260616]
```
