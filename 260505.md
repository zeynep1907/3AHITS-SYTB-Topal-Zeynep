## Zusammenfassung Theorie

+ `if [ Bedingung ]` … `then` … `fi` → Grundstruktur
+ `[ ]` = test-Kommando für Bedingungen
+ `if / else` → Alternative Ausführung wenn Bedingung falsch

Bedingungen:

+ `-n "$var"` → Variable ist nicht leer
+ `-r file` → Datei ist lesbar
+ `-s file` → Datei hat Inhalt

Logische Operatoren:

+ `&&` → UND
+ `||` → ODER
+ `!` → NICHT

Vergleiche:

+ Zahlen: `-gt, -lt`, etc. oder mit `(( ))`
+ Strings: `= , !=`

Shell Arithmetic:

+ `(( ))` → für Zahlenvergleiche (wie in C)
+ Kein `$` bei Variablen nötig
+ `$USER` → aktueller Benutzer (Umgebungsvariable)

## Übung (Maximum)
Schreibe ein bash Skript das 2 Zahlen als Argumente aus der Kommandozeile übernimmt. Die größere der beiden Zahlen soll ausgegeben werden.

# 

Zuerst wurde im Terminal eine neue Datei für das Skript erstellt. Dafür wurde der Befehl
`nano max.sh` eingegeben, um den Editor zu öffnen.

Anschließend wurde in das Skript folgender Code eingefügt:

```

# Prüfen ob 2 Argumente übergeben wurden
if [ -z "$1" ] || [ -z "$2" ]
then
  echo "Bitte 2 Zahlen eingeben!"
  exit 1
fi
 
# Vergleich der beiden Zahlen

then
  echo "Die größere Zahl ist: $1"

fi
```

Danach wurde das Skript mit dem Befehl
`chmod +x max.sh`

Zum Schluss wurde das Skript getestet, indem es mit zwei Zahlen gestartet wurde, zum Beispiel:

## Übung (Directory)
Schreibe ein Skript `makedir.sh` das mit einem Argument aufgerufen wird.

```
$ ./makedir.sh xyz
```

Ein Directory mit dem Namen `xyz` soll angelegt werden falls es nicht existiert. Im Directory lege eine Datei mit dem Namen `xyz.txt` und Inhalt `xyz` an.

Existiert das Directory bereits so soll gefragt werden ob das Directory gelöscht werden darf. Bei dieser Abfrage soll angegeben werden wie viele Files sich im Directory befinden.

```
Soll das Directory "xyz" (mit 5 Files) gelöscht werden? [j|n]: 
```

+ Auswahl `j`: Das Directory wird gelöscht und wieder wie oben angelegt.
+ Auswahl `n`: Das Skript wird beendet.

#

Zuerst wurde mit dem Befehl `nano makedir.sh` eine neue Skriptdatei erstellt und geöffnet.

Anschließend wurde in das Skript folgender Code eingefügt:

```
#!/bin/bash
 
echo "Script gestartet"
 
if [ -z "$1" ]

then

  echo "Bitte einen Namen eingeben!"

  exit 1

fi
 
dir=$1
 
if [ -d "$dir" ]

then

  count=$(ls -1 "$dir" | wc -l)

  echo "Soll das Directory \"$dir\" (mit $count Files) gelöscht werden? [j|n]: "

  read answer
 
  if [ "$answer" = "j" ]

  then

    rm -r "$dir"

  else

    echo "Abgebrochen."

    exit 0

  fi

fi
 
mkdir "$dir"

echo "$dir" > "$dir/$dir.txt"
 
echo "Fertig!"
```

Danach wurde das Skript mit `chmod +x makedir.sh` ausführbar gemacht und mit `./makedir.sh xyz` ausgeführt.

Ergebnis:

```                             
┌──(kali㉿kali)-[~]
└─$ nano makedir.sh
                                 
┌──(kali㉿kali)-[~]
└─$ chmod +x makedir.sh
                              
┌──(kali㉿kali)-[~]
└─$ ./makedir.sh xyz
Script gestartet
Soll das Directory "xyz" (mit 1 Files) gelöscht werden? [j|n]: 
n
Abgebrochen.
                                    
┌──(kali㉿kali)-[~]
└─$ ./makedir.sh xyz
Script gestartet
Soll das Directory "xyz" (mit 1 Files) gelöscht werden? [j|n]: 
j
Fertig!
```

## Übung (number lines script)
Schreibe ein Skript `number.sh` das von der Kommandozeile aus aufgerufen werden kann.

Angenommen es gibt die Datei `test.txt` mit Inhalt:

```
bbb eins
ccc zwei
aaa drei
```

Grundsätzlich kann das Skript mit einer Datei als Argument ausgeführt werden:

```
$ ./number test.txt
$ cat test.txt

1 bbb eins
2 ccc zwei
3 aaa drei
```

Es werden die einzelnen Zeilen nummeriert (dafür kann das Tool nl verwendet werden). Achtung: das Skript soll die Datei verändern nicht ausgeben.

Sollte die Datei nicht exisitieren, nicht lesbar sein oder leer sein soll ein entsprechender Fehlertext ausgegeben werden.

Es soll weiters auch möglich sein dem Tool Daten über stdin zu übergeben (wenn keine Datei angegeben wurde):

```
$ sort test.txt | ./number.sh

1 aaa drei
2 bbb eins
3 ccc zwei
```

Hinweis: `/dev/stdin` kann in der Kommandozeile wie ein Dateiname verwendet werden und liefert die Daten von stdin.

Die Verwendung der Option `-?` soll dann noch zur Ausgabe eines Hilfetexts führen:

```
number.sh: number lines of input
usage: number.sh [FILE]
FILE ... path to readable file of nonzero length
if FILE is omitted data is read from standard input
```

Hinweis: der Befehl `exit` beendet sofort die Skriptabarbeitung.

#

Zuerst wurde im Terminal mit dem Befehl `nano number.sh` eine neue Skriptdatei erstellt. 

Anschließend wurde der vorgegebene Bash-Code in den Editor eingefügt und gespeichert:

```
#!/bin/bash
 
if [ "$1" = "-?" ]
then
  echo "number.sh: number lines of input"
  echo "usage: number.sh [FILE]"
  echo "FILE ... path to readable file of nonzero length"
  echo "if FILE is omitted data is read from standard input"
  exit 0
fi
 
if [ -n "$1" ]
then
  if [ ! -f "$1" ]
  then
    echo "Fehler: Datei existiert nicht!"
    exit 1
  fi
 
  if [ ! -r "$1" ]
  then
    echo "Fehler: Datei nicht lesbar!"
    exit 1
  fi
 
  if [ ! -s "$1" ]
  then
    echo "Fehler: Datei ist leer!"
    exit 1
  fi
 
  tmp=$(mktemp)
  nl "$1" > "$tmp"
  mv "$tmp" "$1"
 
else
  nl /dev/stdin
fi
```

Danach wurde die Datei mit `chmod +x number.sh` ausführbar gemacht, damit das Skript direkt im Terminal gestartet werden kann.

Im nächsten Schritt wurde eine Textdatei erstellt. Dafür wurde der Befehl `nano test.txt` verwendet und anschließend folgender Inhalt in die Datei geschrieben:

```
bbb eins
ccc zwei
aaa drei
```

Nach dem Speichern der Datei wurde das Skript mit der Datei als Argument ausgeführt: `./number.sh test.txt`

Das Skript nummerierte die Zeilen der Datei und überschreibt die ursprüngliche Datei mit den nummerierten Zeilen.

Zum Schluss wurde mit dem Befehl `cat test.txt` der Inhalt der Datei ausgegeben. Dabei wurde folgendes Ergebnis angezeigt:

```                        
┌──(kali㉿kali)-[~]
└─$ nano number.sh    

┌──(kali㉿kali)-[~]
└─$ chmod +x number.sh  
                 
┌──(kali㉿kali)-[~]
└─$ nano test.txt    

┌──(kali㉿kali)-[~]
└─$ ./number.sh test.txt  

┌──(kali㉿kali)-[~]
└─$ cat test.txt
     1  bbb eins
     2  ccc zwei
     3  aaa drei
```

## Übung (Stundenplan V2)
Schreibe ein Skript das aufgrund der aktuellen Zeit das aktuell Fach laut Stundenplan ausgibt. Pausen sind vereinfacht einem Fach zuzurechnen. Berücksichtige nur einen Wochentag, d.h. das Skript funktioniert nur an einem Donnerstag.

```
$ ./splan2.sh
Donnerstag 11:00 SYTB
```

#

Zuerst wurde im Terminal die Skriptdatei erstellt und geöffnet: `nano splan2.sh`

Anschließend wurde der ursprüngliche Code eingefügt, bei dem das Skript nur an einem Donnerstag funktioniert:

```
#!/bin/bash
 
# Wochentag prüfen
day=$(date +%A)
 
if [ "$day" != "Thursday" ]
then
  echo "Dieses Skript funktioniert nur an einem Donnerstag."
  exit 1
fi
 
# aktuelle Stunde holen
hour=$(date +%H)
 
# Stundenplan (Beispielzeiten)
if [ $hour -lt 10 ]
then
  subject="Frei"
elif [ $hour -lt 12 ]
then
  subject="SYTB"
elif [ $hour -lt 14 ]
then
  subject="Pause"
elif [ $hour -lt 16 ]
then
  subject="Mathe"
else
  subject="Ende"
fi
 
# Ausgabe
echo "Donnerstag $(date +%H:%M) $subject"
```

Danach wurde das Skript mit `chmod +x splan2.sh` ausführbar gemacht und mit `./splan2.sh xyz` ausgeführt.
 
Ergebnis:

```                              
┌──(kali㉿kali)-[~]
└─$ nano splan2.sh
                                  
┌──(kali㉿kali)-[~]
└─$ chmod +x splan2.sh
                                   
┌──(kali㉿kali)-[~]
└─$ ./splan2.sh         
Dieses Skript funktioniert nur an einem Donnerstag.
```

Da es nur am Donnerstags funktioniert und heute Dienstag ist wurde das Skript angepasst.

Dazu wurde die Datei erneut geöffnet: `nano splan2.sh`

Im Code wurde anschließend den Wochentag von Thursday auf Tuesday geändert:

```

then

then

then
  subject="SYTB"
elif [ $hour -lt 14 ]
then
  subject="Pause"
```
