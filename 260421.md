## Zusammenfassung Theorie

+ `let` = speichert Ergebnis in Variable
+ `expr` = gibt Ergebnis aus
+ `$(())` = moderne Berechnung
+ `(())`= ohne Ausgabe, für kurze Operationen
+ Operatoren: `+ - * / % ** ++ --`

## Übung (Multiplizierer)

Erstelle ein Skript das 2 Zahlen als Kommandozeilenargumente übernimmt. Multipliziere diese Zahlen und gib das Ergebnis aus, verwende jede der 3 besprochenen Methoden.
#

Zuerst wurde ein Shellskript erstellt mit dem Befehl:`nano multiplizierer.sh`

Anschließend wurde in das Skript folgender Code eingefügt:

```
#!/bin/bash

zahl1=$1
zahl2=$2

let ergebnis1=zahl1*zahl2
echo "let Ergebnis: $ergebnis1"

ergebnis2=$(expr $zahl1 \* $zahl2)
echo "expr Ergebnis: $ergebnis2"

ergebnis3=$((zahl1 * zahl2))
echo "(( )) Ergebnis: $ergebnis3"
```
Danach wurde die Datei gespeichert und der Editor geschlossen.

Im nächsten Schritt wurde das Skript ausführbar gemacht mit:
`chmod +x multiplizierer.sh`

Anschließend wurde das Skript mit zwei Zahlen ausgeführt:
`./multiplizierer.sh 3 4`

Alle drei Berechnungen lieferten das gleiche Ergebnis.

```
──(kali㉿kali)-[~]
└─$ nano multiplizierer.sh
                        
┌──(kali㉿kali)-[~]
└─$ chmod +x multiplizierer.sh                     
                      
┌──(kali㉿kali)-[~]
└─$ ./multiplizierer.sh 3 4                        
let Ergebnis: 12
expr Ergebnis: 12
(( )) Ergebnis: 12
```

## Übung (Werkstatt Summe)

Schreibe ein shell Script dass die Summe aller Beträge in klassenkassa.csv mit dem Text Werkstatt in ermittelt.

Anleitung:
+ Verwende grep und cut zum filtern.
+ Die Beträge stehen nun auf einzelnen Zeilen. Verwende paste um diese zu einer Zeile zusammenzufassen – mit paste kann ein Ausdruck der Form 15+13+42+23 erstellt werden.
+ Verwende command substitution um den Berechnungs-Ausdruck in einer Variable zu speichern
+ Verwende bash Arithmetik $(( expr )) um das Ergebnis auszurechnen
#

Zuerst wurde die Datei `klassenkassa.csv` erstellt:
`nano klassenkassa.csv`

Anschließend wurde der gesamte Datensatz (Name, Datum, Betrag und Kategorie) in die Datei eingefügt und gespeichert.

Danach wurde ein Shell-Skript erstellt mit folgendem Befehl:
`nano werkstatt_summe.sh`

In die Datei wurde zuerst folgender Code geschrieben:

```
#!/bin/bash

ausdruck=$(grep "Werkstatt" klassenkassa.csv | cut -d "," -f 3 | paste -sd "+")
summe=$(echo "$ausdruck" | bc)

echo "Summe Werkstatt: $summe"
```

Das Skript wurde ausführbar gemacht und gestartet:

`chmod +x werkstatt_summe.sh`
`./werkstatt_summe.sh`

```
┌──(kali㉿kali)-[~]
└─$ nano klassenkassa.csv    

┌──(kali㉿kali)-[~]
└─$ nano werkstatt_summe.sh
                                
┌──(kali㉿kali)-[~]
└─$ chmod +x werkstatt_summe.sh

┌──(kali㉿kali)-[~]
└─$ ./werkstatt_summe.sh

```

## Übung (Zeitmessung)
Schreibe 2 Skripts: time_start.sh und time_stop.sh. Bei Aufruf von time_stop.sh wird die Anzahl der Sekunden ausgegeben die seit dem letzten Aufruf von time_start.sh vergangen sind.

Hinweis 1: verwende date um die Anzahl der Sekunden seit 01.01.1970 herauszufinden (die UNIX Zeit bezieht sich immer auf diesen Referenzpunkt).

Hinweis 2: Speichere die Zeit in time_start.sh in einer, mit mktemp erzeugten, temporären Datei
#

Zuerst wurde ein Skript erstellt: `nano time_start.sh`

Das Skript speichert die aktuelle UNIX-Zeit in einer temporären Datei.


```
#!/bin/bash
 
file=$(mktemp)
date +%s > $file
 
echo "Startzeit gespeichert"
```

Danach wurde ein zweites Skript erstellt:`ano time_stop.sh`

Dieses Skript liest die gespeicherte Startzeit aus und berechnet die Differenz zur aktuellen Zeit.

```
#!/bin/bash

file=$(ls /tmp | grep tmp)

start=$(cat /tmp/$file)
now=$(date +%s)

diff=$((now - start))

echo "Vergangene Sekunden: $diff"
```

Beide Skripte wurden ausführbar gemacht:

`chmod +x time_start.sh time_stop.sh`

Dann wurde zuerst das Start-Skript ausgeführt:
`./time_start.sh`

Nach einer kurzen Wartezeit wurde das Stop-Skript ausgeführt:
`./time_stop.sh`

```
┌──(kali㉿kali)-[~]
└─$ nano time_start.sh     
            
┌──(kali㉿kali)-[~]
└─$ nano time_stop.sh 
           
┌──(kali㉿kali)-[~]
└─$ chmod +x time_start.sh time_stop.sh

┌──(kali㉿kali)-[~]
```         

## Übung (Random Number)
$RANDOM erzeugt Zahlen zwischen 0 und 32767. Das ist nicht immer hilfreich. Schreibe ein Skript random.sh wo über 2 Grenzen (Argumente des Skripts) der gewünschte Wertebereich vorgegeben werden kann. Zum Beispiel generiert ./random.sh 10 45 eine zufällige Zahl im Bereich von 10 bis 45 (jeweils inklusive).
# 

Zuerst wurde ein neues Shell-Skript erstellt:
`nano random.sh`

In das Skript wurde folgender Code eingefügt:

```
#!/bin/bash
min=$1
max=$2
zahl=$((RANDOM % (max - min + 1) + min))
echo "Zufallszahl: $zahl"
```

Das Skript wurde ausführbar gemacht:
`chmod +x random.sh`

Das Skript wurde mit zwei Grenzen gestartet:
`./random.sh 10 45`

```
┌──(kali㉿kali)-[~]
└─$ nano random.sh    
                                
┌──(kali㉿kali)-[~]
└─$ chmod +x random.sh                 
            
┌──(kali㉿kali)-[~]
└─$ ./random.sh 10 45
Zufallszahl: 16
 ```
