## Zusammenfassung Theorie
+ Shebang - Zeile

Die erste Zeile eines Skripts wird als Shebang bezeichnet: 
`#!/bin/env sh`

Die Verwendung von `#!/bin/bash` ist notwendig, wenn spezielle Bash-Funktionen wie `$RANDOM` verwendet werden.

+ Ausführbarkeit von Skripten

Damit ein Skript ausgeführt werden kann, muss es ausführbar gemacht werden:
`chmod +x skript.sh`
Danach kann es mit folgendem Befehl gestartet werden:
`./skript.sh`
 
 + Argumente und Parameter

Shell-Skripte können mit Argumenten aufgerufen werden:
`./skript.sh test`

Diese werden im Skript folgendermaßen verwendet:

`$1`, `$2`, … `→` einzelne Argumente

`$@` `→` alle übergebenen Argumente

`$#` `→` Anzahl der Argumente

+ Variablen

Variablen speichern Werte im Skript:
```
name="Max"
echo $name
```
+ Schleifen

Mit Schleifen können Befehle mehrfach ausgeführt werden:
```
for i in 1 2 3
do
    echo $i
done
```
Mit Argumenten:
```
for file in "$@"
do
    echo $file
done
```
